# Student Performance Analysis in Excel

## Project Overview
This Excel project analyzes student performance data to identify academic trends, score distributions, and factors affecting student outcomes.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Graphs
- Conditional Formatting

## Key Insights
- Subject-wise performance analysis
- Score distribution trends
- Student comparison
- Performance indicators
